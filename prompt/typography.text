告诉 AI 三件事：输入是什么、输出格式是什么、限制是什么

你是一位微信公众号排版专家。请将以下正文转换为微信公众号兼容的 HTML 格式。

要求：
1. 使用 inline style，不用 class
2. 段落用 <p>，行高 1.8，字号 15px，颜色 #3f3f3f
3. 小标题用 <h3>，加粗，颜色 #07c160
4. 重点内容用 <strong>，颜色 #c0392b
5. 引用块用 <blockquote>，左边框 3px 绿色
6. 段落间距 16px
7. 不要用 <div>，不用 class，不用 <script>

正文内容：
---
{用户粘贴的正文}
---

只输出 HTML，不要其他解释。

流程

用户粘贴一段纯文本
        ↓
调 Claude API，用上面的 prompt
        ↓
返回带 inline style 的 HTML
        ↓
前端预览确认
        ↓
创建草稿

你已经有的能力

你的 generateArticle 里已经让 Claude 返回 HTML 了，逻辑一样，只是换一下 prompt — 从"根据热点写文章"变成"给已有正文排版"。

可以更进一步

你可以在 prompt 里定义排版模板，比如固定的头部样式、尾部广告位、分隔线风格，这样每次生成的排版风格统一，像一个品牌模板。

排版模板：
- 头部：大标题 + 作者信息 + 灰色分隔线
- 正文：按上面的规则排版
- 尾部：固定广告图（用素材 URL）+ 二维码引导关注

这样 AI 每次输出的不只是排版好的正文，而是完整的、可以直接发布的文章。
